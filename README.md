# El-Mo - iOS Musculation App

A comprehensive iOS fitness and musculation training application designed to help users track their workouts, manage training plans, and monitor their progress.

## Features

- 💪 **Workout Tracking** - Track your exercises, sets, reps, and weights
- 📊 **Progress Monitoring** - Visualize your fitness progress over time
- 📅 **Training Plans** - Pre-built and customizable workout routines
- 🎯 **Exercise Database** - Extensive library of exercises with instructions
- 📱 **User-Friendly Interface** - Clean and intuitive design
- ⏱️ **Workout Timer** - Built-in rest and exercise timers

## Requirements

- iOS 14.0 or later
- iPhone 12 or later (recommended)
- Xcode 13.0 or later (for development)
- Swift 5.5 or later

## Installation

### For Users

1. Download the app from the App Store
2. Tap "Get" and authenticate with your Apple ID
3. Wait for the installation to complete
4. Open the app and create your account

### For Developers

1. Clone the repository:
   ```bash
   git clone https://github.com/iinsolito58-spec/El-Mo.git
   cd El-Mo
   ```

2. Install dependencies (if using CocoaPods):
   ```bash
   pod install
   ```

3. Open the project in Xcode:
   ```bash
   open El-Mo.xcworkspace
   ```

4. Select your target device and build the project (⌘B)

5. Run the app (⌘R)

## Getting Started

1. Launch the app
2. Create an account or log in
3. Choose a training plan or create a custom one
4. Start logging your workouts
5. Monitor your progress with analytics
